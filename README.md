# -Weather-Data-Analysis-and-Prediction

📌 Project Overview  This project focuses on analyzing historical weather data and predicting future temperature trends using time series analysis and basic regression techniques. It helps in understanding how weather patterns change over time and how data-driven models can be used for prediction.

📌 Features

🔍 Search weather by city name (India-focused)

⌨️ Press Enter to search instantly

🌡️ Displays temperature, weather condition, humidity, and wind speed

🕒 Stores and loads recent search history

⚡ Fast and lightweight UI

🌐 Uses OpenWeatherMap Geocoding & Weather APIs
